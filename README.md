# GoxSolana

GoxSolana adalah platform Web3 berbasis Solana dengan fitur:
- Wallet Connect (Phantom, Solflare, Backpack)
- NFT Minting (Metaplex SDK)
- Staking & Airdrop
- Marketplace NFT

## 🚀 Setup
```bash
git clone https://github.com/username/goxsolana
cd goxsolana
npm install
npm start
